# Materials gallery assets: licences

Every file in this directory is procedural. `gen_assets.py` writes all of them (meshes, textures,
environments, materials, scenes and `assets.toml`) with the Python 3 standard library. They are
part of DEngine and under the repository's licence. **No third-party file is committed here.**

| Files | What | Origin |
|---|---|---|
| `meshes/*.gltf` | UV sphere, card, box, open cylinder (glTF 2.0, buffer embedded) | generated by `gen_assets.py` |
| `textures/*.png` | checker, cutout checker, leaf mask, bump normal map | generated by `gen_assets.py` |
| `env/*.exr` | sky (64 × 32) and uniform (8 × 4) environments, uncompressed half-float OpenEXR | generated by `gen_assets.py` |
| `materials/*.mat.toml`, `scenes/*.scene.toml`, `assets.toml` | gallery materials, scenes, manifest | generated by `gen_assets.py` |

## Khronos glTF sample models (stand-ins)

The DENG-307 issue suggests these models from the Khronos glTF Sample Assets repository
(<https://github.com/KhronosGroup/glTF-Sample-Assets>) for the extension tests. None of them is
committed: each is between one and tens of megabytes with its textures, and the repository keeps
golden-test data small. The `materials_khr_samples` scene uses procedural stand-ins that show the
same parameters instead:

| Khronos model | What it tests | Stand-in in `scenes/khr_samples.scene.toml` |
|---|---|---|
| ClearCoatTest | `KHR_materials_clearcoat`: coat factor, coat roughness | a 3 × 3 grid of spheres: coat 0 / 0.5 / 1 × coat roughness 0 / 0.3 / 0.7 over a rough blue base |
| SheenChair | `KHR_materials_sheen`: a fabric | a seat, a back and legs of boxes in a velvet (sheen colour and roughness over a dark base) |
| IridescenceLamp | `KHR_materials_iridescence` | three soap-film spheres with rising thickness ranges |
| TransmissionTest | `KHR_materials_transmission`, `KHR_materials_volume` | four transmissive spheres (roughness 0 and 0.15 thin, thickness 0.6 with a green attenuation) before a checker wall |
| AnisotropyBarnLamp | `KHR_materials_anisotropy` | a brushed-metal shade (anisotropy 0.9) beside a plain one |

Before a later change commits any of the Khronos models:

1. Check the licence in the model's own `README.md` and `LICENSE.md` in the sample repository.
   Most models there are CC-BY 4.0, some are CC0, and some carry other licences or trademark
   notes.
2. Commit only models whose licence allows redistribution.
3. Record each model here with its licence, copyright holder and the attribution its licence asks
   for, and keep the stand-in when a model does not qualify.

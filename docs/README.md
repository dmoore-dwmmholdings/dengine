# DEngine documentation

The project documentation (architecture, module pages, decisions, sprint reports, verification
backlog) lives in the **Trama space `DENG`**. [`agents/DOCS.md`](agents/DOCS.md) says what goes
there and who keeps it up to date.

In this repo:

- [`../SPEC.md`](../SPEC.md): the technical specification.
- [`building.md`](building.md): presets, toolchains and how to build and test.
- [`agents/`](agents/): how the agent build loop works (orchestrator, worker, conventions, docs).
- [`modules/_template.md`](modules/_template.md): the section layout of a Trama `Module:` page.
